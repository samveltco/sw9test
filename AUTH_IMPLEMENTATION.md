# Система аутентификации для Landing Page

## Обзор

Реализована полная система аутентификации для landing page с использованием localStorage. Система включает регистрацию, вход, выход и управление состоянием пользователя.

## Архитектура

### 1. Сервис аутентификации (`src/services/authService.ts`)

Основной сервис для работы с аутентификацией:

- **Регистрация пользователей** - создание новых аккаунтов
- **Вход пользователей** - аутентификация по email и паролю
- **Выход** - очистка данных сессии
- **Проверка авторизации** - определение статуса пользователя
- **Управление данными** - CRUD операции с пользователями

#### Интерфейсы:
```typescript
interface User {
    id: string;
    firstName: string;
    lastName: string;
    email: string;
    mobilePhone: string;
    streetAddress: string;
    suite: string;
    city: string;
    state: string;
    country: string;
    zip: string;
    userType: 'contractor' | 'client';
    createdAt: string;
}

interface AuthData {
    user: User;
    token: string;
}
```

### 2. Хук useAuth (`src/hooks/useAuth.ts`)

React хук для управления состоянием аутентификации:

- **Состояние пользователя** - текущий авторизованный пользователь
- **Статус авторизации** - boolean флаг авторизации
- **Состояние загрузки** - индикатор процесса
- **Методы аутентификации** - login, register, logout, updateUser

### 3. Компоненты

#### LandingPage
Главная страница с условным отображением контента в зависимости от статуса авторизации.

#### SignInModal
Модальное окно входа с валидацией формы и обработкой ошибок.

#### SignUpStep1Modal
Первый шаг регистрации - выбор типа пользователя (contractor/client).

#### SignUpStep2Modal
Второй шаг регистрации - заполнение персональных данных.

#### UserInfo
Компонент отображения информации о текущем пользователе.

## Функциональность

### Регистрация
1. **Шаг 1**: Выбор типа пользователя
   - Contractor (ищет работу)
   - Client (нанимает подрядчиков)

2. **Шаг 2**: Заполнение формы
   - Персональные данные
   - Контактная информация
   - Адрес
   - Пароль и подтверждение
   - Согласие с условиями

### Вход
- Аутентификация по email и паролю
- Валидация данных
- Обработка ошибок
- Автоматическое обновление состояния

### Управление сессией
- Автоматическое сохранение в localStorage
- Проверка авторизации при загрузке
- Безопасный выход с очисткой данных

## Хранение данных

### localStorage ключи:
- `vaylant_auth` - данные авторизации (токен + пользователь)
- `vaylant_users` - список всех зарегистрированных пользователей

### Структура данных:
```json
{
  "user": {
    "id": "unique_id",
    "firstName": "John",
    "lastName": "Doe",
    "email": "john@example.com",
    "userType": "contractor",
    "createdAt": "2025-01-01T00:00:00.000Z"
  },
  "token": "token_timestamp_random"
}
```

## Безопасность

### Текущие меры:
- Валидация форм на клиенте
- Проверка уникальности email
- Минимальная длина пароля (6 символов)
- Проверка совпадения паролей

### Рекомендации для продакшена:
- Хеширование паролей (bcrypt)
- JWT токены с истечением срока
- HTTPS соединение
- Серверная валидация
- Rate limiting для API

## Использование

### Базовое использование:
```typescript
import { useAuth } from '../hooks/useAuth';

const MyComponent = () => {
    const { user, isAuthenticated, login, logout } = useAuth();
    
    if (isAuthenticated) {
        return <div>Welcome, {user?.firstName}!</div>;
    }
    
    return <button onClick={() => login('email', 'password')}>Login</button>;
};
```

### Проверка авторизации:
```typescript
import { authService } from '../services/authService';

if (authService.isAuthenticated()) {
    const user = authService.getCurrentUser();
    console.log('Current user:', user);
}
```
